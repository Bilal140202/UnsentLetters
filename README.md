## 🌟 Overview
**UnsentLetters** is a beautifully crafted platform for composing heartfelt letters that were never meant to be sent. Powered by Supabase for real-time data and React/Vite for a blazing-fast user experience.

## 🚀 Key Features
- 🛡️ **Anonymous First:** Write freely without judgment or identity disclosure.
- ⚡ **Real-Time Backend:** Supabase powers instant data sync and secure storage.
- 🎨 **Immersive UI:** Tailwind CSS-crafted interface designed for emotional, reflective writing.
- 🔒 **Row-Level Security:** Supabase RLS ensures data privacy at the database level.

## 🛠️ Technology Stack
- **Frontend:** React, TypeScript, Vite
- **Backend/DB:** Supabase (PostgreSQL)
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
