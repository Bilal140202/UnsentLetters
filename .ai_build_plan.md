# UnsentLetters - AI Build Blueprint

A React/Vite application backed by Supabase for storing and sharing anonymous unsent letters.

## Goal
Maintain a performant, privacy-respecting platform where users can anonymously write and optionally share letters.

## Tech Stack
- **Frontend:** React, Vite, TypeScript.
- **Styling:** Tailwind CSS.
- **Backend/DB:** Supabase (check supabase/ for schema migrations).
- **Tooling:** Bun / NPM.

## AI Guidelines
1. All Supabase schema changes must be versioned as migrations inside supabase/migrations/.
2. RLS (Row Level Security) policies must be reviewed before any data-model change.
3. Never commit .env files with real Supabase credentials.
4. Keep .ai_build_plan.md in the repository for architectural continuity.
